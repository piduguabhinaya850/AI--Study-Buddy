# 📚 AI Study Buddy

AI Study Buddy is an intelligent learning assistant that helps students 
understand concepts, generate summaries, and create quizzes using AI.

## 🚀 Features
- Ask questions and get explanations
- Upload notes for summarization
- Automatic quiz generation
- Simple web interface using Streamlit

## 🛠 Technologies Used
- Python
- Streamlit
- OpenAI GPT API
- Natural Language Processing (NLP)

## ⚙️ How to Run

1. Install dependencies:
pip install -r requirements.txt

2. Add your API key in .env file:
OPENAI_API_KEY=your_api_key_here

3. Run the app:
streamlit run app.py
